# 1분점검 (Stock Quick Check)

한국 주식 종목의 최신 뉴스, 토론방 분위기, 위험 신호를 한 줄로 요약해주는 투자 전 점검 도구입니다.

## 시작하기

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

## 환경변수

`.env.local` 파일에 다음을 추가:

```
ANTHROPIC_API_KEY=sk-ant-api...
```

Vercel에 배포할 때는 프로젝트 설정에서 같은 환경변수를 추가하세요.

## 배포

자세한 배포 방법은 `배포_가이드.md` 를 참고하세요.

## 면책 조항

본 서비스는 정보 제공 목적이며, 투자 자문이 아닙니다. 모든 투자 판단과 결과는 이용자 본인의 책임입니다.
